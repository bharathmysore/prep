## Linking Rules

- Coding questions should link to canonical prompts under `coding/cpp/<category>/questions.md`.
- Coding answer summaries should link to implemented solutions under `coding/cpp/<category>/solutions.md`.
- If a needed coding prompt does not exist, add it to the right coding category, implement or explicitly mark the solution status, and update the category's pattern/tag maps before linking it here.
- Design questions should link to canonical prompts under `system_design/`.
- If a needed design prompt does not exist, add it to the right company guide and update `system_design/design_questions_toc.md` before linking it here.
